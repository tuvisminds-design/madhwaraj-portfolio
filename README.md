# Madhwaraj Kulkarni — Portfolio

Personal portfolio for Madhwaraj Kulkarni — **Business Analyst | Aspiring AI Product Manager**. Built with Next.js (App Router), TypeScript, and Tailwind CSS v4.

Content is synced with Madhwaraj’s Notion profile (`Madhwaraj Kulkarni`), resume, and process case-study library (SpeakEasy AI Speech Preparation Tool, AI chatbot specs, BRDs, as-is workflows, academic projects, and automation studies).

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. **Directly from Cursor**: Click the **Publish** button in the top bar of this Cursor chat to connect Vercel and get a live `.vercel.app` link in one click.
2. **Or via Vercel Dashboard**:
   - Create/save the repository using the **Create repo** pill in Cursor (or import `tuvisminds-design/madhwaraj-portfolio` on [vercel.com/new](https://vercel.com/new)).
   - Select the repository in Vercel and click **Deploy** (zero configuration needed — Vercel automatically detects Next.js).

## Stack

- Next.js App Router (`output: "export"` compatible with both Vercel and GitHub Pages)
- TypeScript
- Tailwind CSS v4

Resume download lives in `public/Resume/Madhwaraj_Kulkarni_Resume.pdf`. Case-study and profile copy lives in `src/data/`.
